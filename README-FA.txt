راهنمای اجرای سایت استودیو معماری شاهرخ خانلی

1) پوشه پروژه را در Visual Studio Code باز کنید.
2) افزونه Live Server را نصب کنید.
3) روی index.html راست‌کلیک و Open with Live Server را انتخاب کنید.
4) صفحه اصلی بدون اسکرول باز می‌شود.
5) مسیر عکس Hero: assets/images/hero.webp
6) صفحات داخلی در پوشه pages قرار دارند.
7) برای تغییر نوشته‌های Hover، فایل index.html را ویرایش کنید.
8) برای تنظیم موقعیت کادرها، فایل css/main.css و کلاس‌های top-left تا bottom-right را تغییر دهید.
